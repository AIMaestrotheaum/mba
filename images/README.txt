# Images folder

The current demo references sample images hosted remotely by Unsplash. This keeps the project lightweight and avoids bundling large image files.

For offline use or a public deployment:
1. Add image files you own or have permission to use into this folder.
2. Update the image URLs in `index.html` and `js/script.js` to relative paths such as `images/product-name.jpg`.
3. Use descriptive filenames, appropriately sized/compressed images and meaningful alt text.
4. Check each image's licensing and attribution requirements before commercial use.

Do not add customer photos or personal information without appropriate permission.
